# Portal de Noticias (React + Node.js + Flat CMS)

Implementación inicial de un portal de noticias usando:

- **Node.js (servidor HTTP nativo)** para backend.
- **Flat CMS (filesystem)** usando archivos JSON en `content/`.
- **React** en frontend para renderizar secciones.

## Secciones incluidas

- Noticias
- Imagen y texto
- Solo texto
- Solo imágenes
- Footer

## Ejecutar en local

```bash
npm run dev
```

Abrir `http://localhost:3000`.
